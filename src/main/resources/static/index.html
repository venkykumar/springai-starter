7 routes
/hello Plain text

Quick smoke test for the running application.

curl http://localhost:8080/hello
/ask Guided prompt

General Spring and Java Q&A with a focused system prompt. Backed by whichever model is active — OpenAI or Anthropic Claude.

curl "http://localhost:8080/ask?message=What%20is%20Spring%20AI"
/nba/player-profile Structured JSON

Returns a typed NBA player profile record from the model.

curl "http://localhost:8080/nba/player-profile?playerName=Stephen%20Curry"
/nba/chat Memory + tools

Use the same conversation ID for multi-turn NBA follow-up questions, and ask for quick player facts through the local NBA tool.

curl "http://localhost:8080/nba/chat?conversationId=warriors-thread&message=Tell%20me%20about%20Stephen%20Curry"
/nba/mcp/recent-games-summary MCP + JSON

Fetch recent-game data through the local MCP server, then return a typed JSON summary for the selected NBA player.

curl "http://localhost:8080/nba/mcp/recent-games-summary?playerName=Stephen%20Curry"
/nba/ask RAG

Ask a question answered from a curated NBA knowledge base. Uses vector similarity search to retrieve relevant context chunks, then passes them to the model to generate a grounded answer.

curl "http://localhost:8080/nba/ask?question=Who+has+the+most+career+three-pointers"
/mcp Local MCP server

Streamable HTTP MCP endpoint exposed by the app for MCP clients. It currently serves the recent-games and supported-players demo tools.

MCP server base endpoint: http://localhost:8080/mcp
